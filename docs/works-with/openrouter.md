# OpenRouter iPhone app: use your OpenRouter API key on iOS, including free models

Vanta is an iPhone and iPad app with **OpenRouter built in**. Paste your OpenRouter key and you can chat with the models OpenRouter offers, including its free model variants. They sit next to your own server, on-device GGUF and MLX models and Apple Intelligence, in one app you buy once.

## Settings at a glance

| Setting | Value |
| --- | --- |
| Where | **Settings → Providers → OpenRouter** |
| API key | Create one at openrouter.ai/keys |
| Models | Choose from OpenRouter's list, such as `meta-llama/llama-3.2-3b-instruct:free` |
| Billing | OpenRouter bills your account directly; Vanta takes nothing |

## Set it up

1. Create an API key at [openrouter.ai/keys](https://openrouter.ai/keys).
2. In Vanta, open **Settings → Providers → OpenRouter** and paste the key.
3. Create a model preset and pick a model from OpenRouter's list.
4. Start a chat. Switch to another model, or to your own server, from the chat's model picker.

## Free models

OpenRouter offers `:free` variants of some models at no cost. Its limits are 20 requests a minute, and 50 requests a day if you've bought fewer than 10 credits (1,000 a day with at least 10). A paid fallback model, if you set one, is billed.

## What works

Streaming works with every model. Tool calling works on models that support it, so MCP tools and web search are available with those. Multimodal models accept images.

Your conversations stay on your iPhone or iPad, whichever model answers: Vanta has no servers and no account, and requests go straight to the address you entered. Stuck? Write to the developer at [ezel964@icloud.com](mailto:ezel964@icloud.com) or use **Settings → About → Contact developer**.
