# Vanta documentation

Start with one model and one conversation. These guides explain how to connect it, where it runs and what to check if something goes wrong.

## Start here

- [Local AI on iPhone and iPad](https://vantaclient.app/local-ai/) — compare on-device models and your own server before choosing a setup.
- [Getting started](https://vantaclient.app/docs/getting-started/) — choose your first model, save a preset and begin a chat.
- [Compatibility](https://vantaclient.app/compatibility/) — understand supported runtimes, images, tools and device limits.
- [Privacy and data flow](https://vantaclient.app/privacy/) — see which requests stay on-device and which go to a service.

## Connect your server

- [LM Studio on iPhone and iPad](https://vantaclient.app/docs/lm-studio/) — enable LAN access and connect to your computer.
- [Ollama on iPhone and iPad](https://vantaclient.app/docs/ollama/) — use Ollama's OpenAI-compatible API from Vanta.
- [vLLM on iPhone and iPad](https://vantaclient.app/docs/vllm/) — connect to a served model with the correct base URL and key.

## Choose another place to run

- [On-device models](https://vantaclient.app/docs/on-device/) — download GGUF or MLX, import GGUF, or use available Apple Intelligence.
- [Cloud providers](https://vantaclient.app/docs/cloud-providers/) — bring an API key and connect an OpenAI-compatible endpoint.

## Add context and tools

- [Files and PDFs](https://vantaclient.app/docs/files-and-pdfs/) — ask about documents and choose a model for images.
- [MCP tools](https://vantaclient.app/docs/mcp/) — connect remote tool servers and understand what they can access.

## Get unstuck

- [Troubleshooting](https://vantaclient.app/docs/troubleshooting/) — identify common connection, model and attachment problems.
- [Support](https://vantaclient.app/support/) — send the developer the details needed to reproduce an issue.
